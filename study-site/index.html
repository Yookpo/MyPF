이 사이트는 프로젝트 소개가 아니라 내가 작성한 DX11 렌더러 코드를 다시 공부하기 위한 노트다. 모든 설명은 실제 코드의 파일:줄에 근거한다.

코드 기준: main @ adee25f · 작성 2026-10-05. 코드가 바뀌면 줄 번호가 어긋날 수 있으니 의심되면 소스를 직접 연다.

학습 경로

정적 구조 → 시간축 → GPU 내부 순서로 읽는다. 앞 페이지의 용어를 뒤 페이지에서 그대로 쓴다.

1 · 정적 구조 Architecture 벽 하나를 그리는 ID3D11Buffer는 누가 만들고, 누가 소유하고, 누가 빌려 쓰는가? 2 · 시간축 Frame Analysis Run 루프 한 바퀴 동안 마우스 움직임과 E 키 한 번은 어떤 함수를 거쳐 픽셀이 되는가? 3 · GPU 내부 Rendering Pipeline 내 코드의 각 Context->…Set… 줄은 파이프라인의 어느 단계를 바꾸고, 그 상태는 다음 Draw까지 어떻게 살아남는가?

읽는 법

세 페이지는 같은 골격을 쓴다.

  1. 이 페이지의 질문 — 페이지 전체를 끌고 가는 질문 하나
  2. 학습 목표 — 페이지를 마치면 설명할 수 있어야 하는 것
  3. 참고 파일 — 열어 둘 소스와 줄 범위
  4. 섹션 — 예측 질문 → 다이어그램 → 코드 흐름 → 함정
  5. 학습 질문 — 확인 / 추론 / 실험. 정답은 접혀 있고 근거 줄이 붙어 있다
  6. 문서와 다른 점 — AGENTS.md 등 문서와 실제 코드가 어긋나는 곳

예측 질문은 답을 보기 전에 소스를 열어 직접 따라가 본 뒤 아래 내용과 맞춰 보는 용도다.
